# 🚗 Used Car Market Analyzer

An end-to-end Exploratory Data Analysis (EDA) project using Python, Pandas, and NumPy to analyze factors affecting used car prices.

## 📌 Project Objective
The objective of this project is to identify the key factors influencing used car prices and extract meaningful business insights from the data.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📊 Key Insights
- Older vehicles generally have lower resale values.
- First-owner cars tend to have higher selling prices.
- Automatic transmission vehicles often command premium pricing.
- Fuel type influences resale value.
- Brand popularity impacts the used car market.

## 📂 Dataset Features
- Car Name
- Manufacturing Year
- Selling Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission Type
- Ownership History
