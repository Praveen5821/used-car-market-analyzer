# 🚗 Used Car Market Analyzer

This project analyzes factors affecting used car prices using Python, Pandas, and NumPy.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Insights
- Older vehicles generally have lower resale values.
- First-owner cars tend to have higher selling prices.
- Automatic transmission vehicles often command premium pricing.
- Fuel type influences resale value.

## Dataset Features
- Car Name
- Year
- Selling Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Ownership History
